Security Vulnerability
======================

If you think you have found a potential security vulnerability in Authlib,
report it through `GitHub private vulnerability reporting
<https://github.com/authlib/authlib/security/advisories/new>`_.

.. warning:: Do not file a public issue.

Please do not disclose this to anyone else. We will retrieve a CVE identifier
if necessary and give you full credit under whatever name or alias you provide.
We will only request an identifier when we have a fix and can publish it in
a release.

Writing a Report
----------------

You may use AI tools to find or describe an issue. In all cases:

1. A human must check the finding before it is reported.
2. The report must include a proof of concept that uses the public Authlib
   API.
3. The report must explain what an attacker can do, and under which
   conditions.

Reports that do not follow these rules may be closed without reply.

The Process
-----------

When we receive a security report, we try to reproduce it. If we need more
information, we ask you in the advisory. Once the issue is confirmed, we fix
it, publish a release, and then publish the advisory.
